a research programme · updated 2026-09-06 · github.com/JacobFV/IBM-1

ibm-1 declares a brain once, as four primitives — fields, anatomy, topologies, processes — and materializes task-specific models from it lazily. an EEG forward model, a hemodynamic model and an audio-visual predictor are different projections of one parameter set, not separate codebases.

the bet is that most of the model is shared across materializations, so every corpus constrains every task. that bet is now testable and, so far, standing: bypassing the shared cortical dynamics costs 324% more loss, so the substrate is load-bearing rather than decorative. the physiology end is declared and falsifiable, and has already lost several arguments to data. the cognitive end is not declared at all, because a schema or a percept is a property of the vector field, not a parameter you set.

§1the four primitives

resolution, bandwidth, datasets, observations, interventions and explicit models are all expressed through four primitives rather than introduced as additional ones.

fieldsF = { x(q) : q ∈ Ω }

an indexed family of state variables. a component is a kind of physical quantity — membrane potential, K⁺ concentration, flow rate — and never an encoding of something else. fields do not share a support: the cortical sheet, the vascular tree and a sensor array are different domains with different notions of distance.

anatomya(q) ∈ [0,1]ᵏ

partitioning systems that map a position into soft memberships over named partitions: 34 cortical areas, 31 thalamic nuclei, 36 brainstem nuclei, 31 spinal levels, 96 skeletal muscles. an atlas is evidence about where things are, not a coordinate system.

topologiesT(i, j)

which materialized state variables may interact through some class of process. tracts, laminar circuits, the vascular tree, peripheral nerves, the lead field from cortex to a contact. spatial structure lives entirely here; there is no universal spatial operator.

processesP = (I, O, T, f, θ)

dynamics over state variables connected by one or more topologies. the pair (f, θ) is implementation — linear, conductance-based, learned — and implementations compete for a process rather than redefining it.

§2materialization

an explicit model is a lazy materialization of the implicit one:

M = materialize(R, r, B, F, A, T, P)

you name spatial regions R, a resolution r(q) over those regions, a bandwidth B(q), and which fields, anatomies, topologies and processes you need. dependency tracing then instantiates only the state variables and processes reachable from the target. the same field can exist at 1 mm across the whole brain and at 50 µm around an electrode at the same time, without instantiating 50 µm state everywhere. resolution earns its cost only where coarse-graining stops commuting with the dynamics.

because the process graph is finite, the core clique is shared across nearly every materialization; R, r and B are the only levers by which the forty entries in the library differ. every materialized model carries provenance: which f was selected per process, which parameters were moved off their prior by evidence and which were not, and where a process was run outside the regime in which its f is meaningful. a prediction resting on prior-dominated structure is not presented with the confidence of one resting on constrained structure.

in the opener, hover a materialization to see the region it names; click to see its inputs and outputs. the node sets are read symbolically from each request — the regions it names, the devices it declares, the state it targets — so the figure is a rendering of the declaration, not of a fit. the retina, cochlea and spinal stub are drawn for orientation; this subject has no geometry for them, and neither does the model pretend to.

the implicit structure exists independently of what any instrument can observe or any materialization can afford. evidence constrains what it constrains; elsewhere the structure remains at its prior. that is the machinery working, not failing.

§4what the cortex is for

the model is not routing around its own dynamics. that is measured by ablation, not argued.

ablation of the audio-visual checkpoint over 24 held-out batches. bypassing the cortex more than triples the loss; freezing its weights or zeroing the association kernel nearly doubles it; severing every long-range edge costs nothing.

four confident wrong numbers

the recurring failure in this programme is measuring over the wrong population, or not checking that a fix landed. each of these produced a confident number before it produced a correct one, and each is recorded because the next agent will make the same mistake in a new place.

  1. a positive association kernel is a diffusion operator. all-positive, fan-in-normalized weights applied eight times per forward are eight rounds of averaging: effective rank fell 1.57 → 1.01 while reconstruction diverged 2.04 → 6.66. a signed kernel holds rank at 3.40. a kernel that cannot subtract can only blur.
  2. the objective went parasitic on its substrate. membrane potential drifted 64 → 430 mV while the loss kept falling, because a 430 mV cortex predicts frames fine. a one-sided viability penalty is what makes the objective mutualistic.
  3. a free readout substitutes for the cortex. a free 4096→306 readout reached skill +0.94 at cortical rank 1.03. constraining the lead field to the ~64 spatial degrees of freedom a 306-channel array resolves raised the reported skill and tripled the rank the cortex used.
  4. a loss in the wrong units flatters itself by 280×. the MEG target normalization was loaded and never applied, so training minimized against an array with 3×10⁴ less variance. every paired skill reported that day — +0.90, +0.96, +0.99 — was measuring the target scale. with the target actually normalized the honest numbers are mse 1.21–1.51 against a 1.41 baseline: skill −0.07 to +0.14, hovering at chance, which is where a stimulus-to-MEG encoder starts.

what did hold: cross-modal association is learned. on the audio-visual run the occipito-temporal edges came out at mean |w| 0.618 against 0.139 for random pairs, 4.4× the baseline, net excitatory and genuinely signed. and the periphery is connectable: 96 muscles, 58 nerve trunks with fibre-class-resolved delay (Ia at 6 ms against C at 550 ms down the same sciatic), four spinal reflex arcs, a 483-port simulator interface.

a loss without a baseline is not a result, and that is not a stylistic preference here, it is the lesson.

§5what is being built

forty materializations are one library, but they fall into six lines of work. each is a different instrument or intervention pressed against the same parameter set, and each has an honest status.

forward models

every instrument, from the same tissue

EEG, MEG, ECoG, laminar LFP, fNIRS and BOLD as observations of ordinary state: a contact potential produced by a lead field, a deoxyhemoglobin field produced by a vascular chain. eeg_forward solves a real 60-channel boundary-element lead field for 13,636 of 13,647 cortical sources.

materializes · lead field real · fusion exact in band
decoding

stimulus and language through the cortex

meg_to_text, speech_envelope, eeg_to_image and inner_speech share the auditory and visual chain with the forward models. the anchor is 235.6 minutes of paired MEG aligned to an audiobook's cochleagram, and the evaluation is skill against explicit baselines on guarded splits.

running · skill at chance · data-bound, not compute-bound
stimulation

TMS, tES, focused ultrasound, DBS

an intervention is externally constrained state, not an input. a coil's field at 20 µs steps, a transducer's pressure at 100 ns, a lead's potential 100 µm from its contacts, each with the thermal safety materialization gating the run. motor_mapping closes coil position to a motor evoked potential through the periphery.

declared · builds · not yet fitted
state and disorder

sleep, anaesthesia, seizure, pharmacology

the slow thalamocortical trajectory as neuromodulator fields on the reticular nucleus and locus coeruleus. the slow oscillation is fitted rather than argued: 1.000 Hz against eight scored N3 nights, and the regime sweep shows oscillation and multistability present with nothing diverging.

regime fitted · attractor landscape admitted, not yet fitted into
the embodied loop

arrays, effectors and a body to close on

invasive_bci and handwriting_bci read an implanted array and write motor drive. the periphery gives them something to drive: 96 named muscles, 58 nerve trunks with fibre-class delays, four reflex arcs, and a 483-port interface a simulator can plug into. segmental reflexes at 16.7–35.7 Hz against 1.8–3.3 Hz for the long cortical loop.

periphery connectable · first closed cycle in the declared graph
surrogates

the cheap views

macro_surrogate is the parcel-level neural-mass materialization built to run ten thousand times; resting_state_fc is coarse in space and coarse in band; encoding_model is the teacher-shaped one. cheap is a materialization choice, not a different model.

trajectory

weeks

naturalistic video at scale, which is bandwidth-bound. blob persistence on held-out video is about 3 GB10-hours once the data exists; two-dimensional motion 15–30. finish the joint schedule over both likelihood terms and show one parameter set beating each single-corpus fit on its own held-out split.

months

re-run the ablation against the corrected long-range prior. wire the four subcortical processes whose anatomy is declared and unused — basal ganglia, hippocampal indexing, replay, cerebellum. the partitions and supports already exist, so these are the cheapest real progress available.

the gate

a stable multi-attractor landscape has to exist before curriculum, schema or reinforcement mean anything. the substrate now admits one, but θ has to be fitted into those regions, which are about 0.05% of the swept parameter space. that is stage 2 work and it is unblocked.

what would falsify the programme. if the joint schedule does not beat single-corpus fits, the shared-substrate claim is wrong and the architecture's main advantage evaporates. if severing long-range edges keeps costing nothing after the prior fix, cross-area communication is not happening and no cognitive stage is reachable. both are measurable within the current compute budget, and both come before scaling further.

§6the corpus and the curriculum

a row in the index is a candidate; a directory in data/sources is a commitment. the candidate index holds 26,399 datasets, 2.55 PB. 601 cards have been committed — 251 datasets, 136 atlases, 125 tools, 46 models, 30 standards, 13 derived geometries — with provenance traced to origin, and 36 are held on disk. most of those licences prohibit redistribution, so the repository commits where the bytes are and what they hashed to; acquiring them is a separate, local act.

  • 52 hemodynamic and metabolic
  • 36 effector, autonomic, interoceptive
  • 36 sensory boundary and stimuli
  • 31 scalp electromagnetic
  • 23 simultaneous multimodal
  • 22 intracranial electromagnetic
  • 17 stimulation response
  • 11 structural and microstructural
  • 10 oracle, synthetic, negative control
  • 8 vascular geometry
  • 5 population and clinical priors

the curriculum is a gated DAG of thirteen stages, five complete and three running. the organizing identity is

∇ log p(θ | D) = ∇ log p(θ) + Σd ∇ log p(Dd | θ)

a curriculum is a schedule over d. materializations are more terms in the same product rather than competing regimes, and the factorization is the parallelization: the multi-materialization trainer fits an audio-visual head and a paired-MEG head onto one shared substrate in a single optimizer step, so anything the two teach each other has to pass through the association kernel.

  1. fan-in-aware gain priorthe divergence was a declaration problem: |L(0)| = 7218 because the gain prior was per edge and a node has 4118 incoming edges
  2. regime selectionfitted to sleep-EDFx N3: slow oscillation at 1.000 Hz, τadapt = 0.12 s, a 43.5 mV swing
  3. per-source spectral fitjoint θ beats the literature prior on all four sources, and beats each source's own fit on none
  4. forced sensory alignmentforcing constrains delta and essentially nothing above it: 0.5–4 Hz r² +0.0033, 8–13 Hz −0.0001
  5. the closed video loopunbounded data, and the stage where per-site tying finally has something to spend 73M parameters on
  6. audio-visual materialization68.9M parameters, 20,000 steps, 4 hours on one GB10; recon 1.77 → 0.185; cross-modal edges 4.4× baseline
  7. the paired MEG anchorrunning; skill at chance, and the eval that says so is the one to trust
  8. multi-materialization, development, schema, reinforcementdeclared as stages; gated on the attractor landscape

cognition is not primarily symbols being passed around. it is the trajectory generated by a nonlinear vector field.

docs/DYNAMICS.md
§7not demonstrated

the honest distance to the cognitive end is that there is no cycle yet.

the materialized graph currently selects a linear implementation for every process, and a linear system has exactly one fixed point. there is no attractor landscape, so there is nothing for a cognitive structure to be. the periphery produced the first closed feedback cycle in the declared process graph; the EEG forward materialization is still acyclic.

  • no task performance. stimulus-to-MEG skill hovers at chance.
  • no video generation. predictions reproduce frame statistics, not content.
  • single seed everywhere. nothing replicated; every result on this page is one run.
  • eleven minutes of video. data, not compute, binds the next milestone.

weights publish to a private hugging face repository; the history was rewritten once to remove 2.9 GB of them, and they are no longer tracked. no licence has been declared for the code yet.
