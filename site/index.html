a research programme · updated 2026-09-06 · github.com/JacobFV/IBM-1

ibm-1 declares a brain once — fields, anatomy, topologies, processes — and materializes task-specific models from it lazily. an EEG forward model, a hemodynamic model and an audio-visual predictor are projections of one parameter set.

the bet: most of the model is shared, so every corpus constrains every task. so far it stands. bypassing the shared cortex costs 324% more loss.

§1design
fieldsF = { x(q) : q ∈ Ω }

state variables on a support. a component is a physical quantity, never an encoding. supports are not shared: the cortical sheet, the vascular tree and a sensor array are different domains.

anatomya(q) ∈ [0,1]ᵏ

soft membership of a position in named partitions. an atlas is evidence about where things are, not a coordinate system.

topologiesT(i, j)

which state variables may interact, through what. all spatial structure lives here; there is no universal spatial operator.

processesP = (I, O, T, f, θ)

dynamics over a topology. (f, θ) is implementation; implementations compete for a process rather than redefining it.

M = materialize(R, r, B, F, A, T, P)

an explicit model names regions R, a resolution r(q) and a bandwidth B(q); dependency tracing instantiates only what is reachable from the target. the same field can sit at 1 mm across the brain and 50 µm around an electrode at once. the forty entries in the library differ only in R, r and B, and each carries provenance: which implementation ran, which parameters evidence moved, and where a process ran outside its regime.

trained weights publish to huggingface.co/brandonin/ibm-1, named by modality, site count, embedding, degree, dynamics revision, objective and git sha; each link is that run's latest checkpoint. WIP entries are declared and build, but have no trained weights yet.

it runs on two GB10 boxes at 300k sites, 93.7M parameters, 2.3 s per step. the binding constraint is data, not compute: eleven minutes of one film, and a 200 GB-a-day connection. next comes naturalistic video at scale, the ablation re-run against the corrected long-range prior, the four subcortical processes whose anatomy is declared and unwired, and fitting θ into the multistable regions of parameter space, without which nothing cognitive means anything.
