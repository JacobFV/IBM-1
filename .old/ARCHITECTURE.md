# Implicit Brain Model 1 (IBM-1) Architecture

- Implicit vs Explicit: The _implicit_ brain model (IBM) is itself a perspective-agnostic model. Explicit models can be _materialized_ from the implicit structure. EG, IBM can be materialized into a ibm-1-eeg-predict, ibm-1-eeg-to-image, ibm-1-meg-to-text, etc. 
- Process before structure: Various interacting processes apply pressure on both internal and surface level state variables. _Processes_ are selectively enabled depending on both the internal and surface-level explicit structure that is materialized. EG,
  - 1-5mm mesoscale cortical structure ion potentiation interaction
  - tractometric structure creates an additional ion potentiation interaction topology

- Common State Variables: I think we should have the following schema:
  - Whole brain 1mm voxel EM field: this is a single state variable even though there are voxels for each position
  - Macro scale structures: a state variable for every major region of the brain including cortical patches (perhaps split by 10-20 or another common system?), subcortical substructures like subdivisions/sectors/territories (maybe that belongs in meso-scale?), and anything else you feel qualifies for this. there will be a lot of very careful hand-wiring to ensure all these state variables will be derived from common knowledge and be useful for observing/testing traditional macro-scale claims like "the p300 emerges from thalamo-cortico-thalamic integration". each state variable has a fixed R^3 position, activity laplacian spectrum distribution, possibly a latent embedding too?

  - Cortical columns: somewhere on the order of 500k nodes arranged with equal spacing along the surface of the cortex. We will use a cortex geometry to assign a position to each node. Note that "cortical column" is not a universally agreed on concept and we've just chosen one of many compromises, mostly informed by the resolution we can expect from the cortex geometry
  - Cortical minicolumns: somewhere on the order of 100m nodes arranged with equal spacing along the surface of the cortex. We will use a cortex geometry to assign a position to each node. Note that we have little information on these and any processes that read from or write to them will be generalizing from a small sample and are likely just speculative simulations/experiments if anything

- Lazy state: Processes and state variables are only introduced if a process applies pressure on them. This also guides the granularity considered. EG, in a BCI simulation using the IBM, it might be informative to simulate the minicolumn activations within a small patch near direct-contact electrodes but usually the minicolumn state and updates that affect it will be disabled. Likewise, researchers can materialize a macro-scale GNN out of the IBM but in most cases this is just misleading and only useful as a surrogate for fast preliminary exploration.
- Uncertainty-aware laplacian state: Many state variables are defined as multivariate gassian components of a laplacian-spectral representation instead of scalar values. This forces processes to model their precision impact without requiring a hard floor on contributions; likewise for working with varying input sources including ground truth datasets, distillation infilled, and other sources. It also enables the modeling interactions between datasets and processes of varying certainty across broad timescales. Hence, updates to a state variable are often described as "applying pressure" rather than merely "updating" and we seek to design an information theoretically verifiable architecture around these ideals as that will objectively inform what to optimize
